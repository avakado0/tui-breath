The application will function as an **Interactive Breathing Guide**, actively leading the user through guided breathing exercises, providing real-time feedback, and meticulously 
tracking the successful completion of each session.

### 1. Core Function: Interactive Guidance

Instead of passive logging, the application will manage the breathing rhythm, making the user an active participant in the exercise.

*   **Guided Sessions:** Users will select from pre-defined breathing patterns (e.g., 4-7-8 Breathing, Box Breathing, Diaphragmatic Breathing) or create custom rhythms.
*   **Real-Time Pacing:** The application will dictate the pace of the breath (e.g., counting breaths, providing visual pacing cues, or playing ambient soundscapes) to keep the 
user synchronized with the exercise.
*   **Session Control:** Users must be able to easily **Start, Pause, and End** the guided session.

### 2. Data & Tracking (The Outcome)

The data logging function now serves to validate the user's engagement and measure their progress against the guided exercise.

*   **Session Metrics:** The system will automatically calculate metrics based on the session data:
    *   Total duration of the session.
    *   Average breath rate achieved.
    *   Consistency score (how closely the user followed the prescribed rhythm).
*   **Progress Visualization:** Visual charts will show the user’s improvement over time (e.g., improved consistency scores, longer sustained sessions).

### 3. User Experience Flow

The flow must prioritize a calm, focused, and intuitive experience.

1.  **Selection:** User selects a breathing exercise.
2.  **Setup:** User sets parameters (e.g., desired session length, desired tempo).
3.  **Guidance:** The application initiates the session, providing clear, non-intrusive audio and visual cues to guide the user’s breath.
4.  **Completion:** The session ends, and the system immediately presents the calculated results and prompts the user to save the session data.
5.  **Review:** The user can review their history, see their progress charts, and select past sessions to revisit.

### Summary of Shift

| Previous Focus (Logging) | **New Focus (Guidance)** |
| :--- | :--- |
| **Passive Recording** | **Active Facilitation** |
| **Data Storage** | **Real-time Feedback & Scoring** |
| **Goal:** To record what happened. | **Goal:** To guide the user to a desired state. |
