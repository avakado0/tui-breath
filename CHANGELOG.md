# Changelog

## 0.3.4 - 2026-06-10

### Changed
- Default Workout Mode (`[w]`) to on when the app opens and when returning to the main menu.
- Replace the Results screen `[s] Save Again` action with `[f] Forget Record`, making auto-save clearer and giving users an explicit way to discard a completed session.

### Fixed
- Remove forgotten sessions from both the session JSON file and history index.
- Make update-checker version comparison tests independent of the current crate version.
